# Stencils

These are stencils I make for tracing images and patterns onto clothes. They can be used for spray-on, but I love using them to draw on lines for reverse applique. I'll add images in of this when I've done it.  

## Rain Frog
Inside a cirlce as it will form the "O" of Frog on a jacket. Inspired by Pheobe Dee's "Froge Sticker" which you should get if you like the pattern. I have it on my phone, which is cool.
